### 3. โครงสร้าง Pseudocode ของระบบควบคุมอัตโนมัติ (A.E.G.I.S. Core Engine)

```text
ALGORITHM: A.E.G.I.S. Autonomous Closed-Loop Decision & Actuation
INPUT: Top-down Canopy Image (OV5640), Analog Telemetry (EC, pH, Temp)
OUTPUT: Diagnosed Class (Healthy, -N, -P, -K) & Dosing Timings (ms)

1. SENSING & FILTERING:
   - Read ADC samples (N=15) -> Apply Insertion-Sort Moving Median Filter
   - Compute Calibrated pH = -8.487 * V + 29.59
   - Compute Temperature-Compensated EC25 = EC_raw / (1.0 + 0.019 * (Temp - 25.0))

2. COMPUTER VISION PREPROCESSING (3-Layer Cropper):
   - Layer 1: Illumination Normalization via Gray-World + CLAHE on L* channel
   - Layer 2: Foliage Mask = (ExG > Otsu) OR (HSV 18..92) OR (CIELAB Halo Chroma > 22)
   - Layer 3: Extract tight bounding box around foliage (224x224 RGB)

3. MULTIMODAL LATE-FUSION PREDICTION:
   - P_vision = 0.40 * P_MobileNetV2 + 0.40 * P_SE_CNN + 0.20 * P_ColorRF
   - P_sensor = Mean(P_LogisticRegression, P_GradientBoosting, P_RandomForest, P_ExtraTrees)
   - P_fused  = 0.45 * P_vision + 0.55 * P_sensor
   - Final Diagnosis = ArgMax(P_fused)

4. TWO-TIER CLOSED-LOOP ACTUATION:
   - IF EC < 0.8 mS/cm -> Tier 1 Baseline Priming: Pulse Pumps 1, 2, 3 equally
   - ELSE IF Diagnosis != Healthy -> Tier 2 AI Correction:
       * IF -N -> Run Peristaltic Pump 1 for 4,000 ms (GPIO 9)
       * IF -P -> Run Peristaltic Pump 2 for 3,500 ms (GPIO 10)
       * IF -K -> Run Peristaltic Pump 3 for 3,500 ms (GPIO 11)
   - SAFETY GUARD: IF (EC > 2.5 mS/cm OR pH < 4.0) -> Force Abort All Dosing
```

### 4. สรุปสมการหัวใจสำคัญ (Core Governing Equations)

1. **สมการแปลงแรงดันสู่กรด-ด่าง (pH Calibration Curve):**
   $$\text{pH} = -8.487 \times V_{\text{analog}} + 29.59$$
2. **การชดเชยอุณหภูมิของสารละลายไฟฟ้าสู่ค่ามาตรฐาน 25°C (EC25):**
   $$\text{EC}_{25} = \frac{\text{EC}_{\text{raw}}}{1.0 + 0.019 \times (T - 25.0)}$$
3. **ดัชนีพืชพรรณพุ่มใบเขียวจัดตัดแสงสะท้อน (Excess Green Index):**
   $$\text{ExG} = 2G - R - B$$
4. **การรวมการตัดสินใจแบบ Late-Fusion Stacking:**
   $$P_{\text{fusion}} = 0.45 \cdot P_{\text{Vision Ensemble}} + 0.55 \cdot P_{\text{Sensor Ensemble}}$$
