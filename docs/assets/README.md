# Academic Poster QR Code Assets & Sizing Guidelines

This directory contains print-ready QR code assets linking directly to the A.E.G.I.S. academic references repository page:  
**Target URL:** `https://github.com/nottyzez/A.E.G.I.S-Ai/blob/main/REFERENCES.md`

## Assets Included
* `references_qr.png` (and `qr_code.png`): High-resolution raster image (1440 × 1440 px, 300+ DPI print-ready).
* `references_qr.svg` (and `qr_code.svg`): Scalable vector graphic for lossless professional printing.

## Print Sizing & Placement Specifications

| Parameter | Specification | Recommendation for Posters (A0 / A1) |
| :--- | :--- | :--- |
| **Standard Print Size** | 35 mm × 35 mm (1.4" × 1.4") | Suitable for standard 1.0 m viewing distance |
| **Walk-by Print Size** | 50 mm × 50 mm (2.0" × 2.0") | For 1.5 – 2.0 m walking traffic in poster halls |
| **Minimum Scan Size** | 25 mm × 25 mm (1.0" × 1.0") | Absolute lower limit for smartphone camera focus |
| **Quiet Zone Margin** | ≥ 4 modules (≥ 4 mm) | Integrated into files; do not crop outer white margin |
| **Resolution** | ≥ 300 DPI | 1440 × 1440 px PNG supports up to 4.8" print size cleanly |
| **Vector Format** | Scalable SVG | Recommended for Illustrator / InDesign vector layout |
| **Placement** | Bottom-right corner | Adjacent to References / Discussion / Acknowledgments |
| **Mounting Height** | 1.2 m – 1.6 m from floor | Human chest / eye level on poster display boards |
| **Call-to-Action (CTA)** | Caption text below QR | *"Scan for Full Literature References & Open-Source Code"* |
| **Surface Finish** | Matte or Satin | Prevents spotlight reflection / glare during photo scan |
