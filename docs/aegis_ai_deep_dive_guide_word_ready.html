1. กลไกคัดกรองอาการระยะแฝง (Symptom-Gated Filtering)

PreprocessingStatistical BiologyZ-Score

📌 ความหมาย

อัลกอริทึมคัดกรองข้อมูลเชิงสถิติชีวเคมี ทำหน้าที่ประเมินระดับการแสดงออกของอาการทางใบพืช โดยใช้ระยะเบี่ยงเบนมาตรฐาน (Z-score) ในปริภูมิสีสม่ำเสมอ เพื่อคัดแยกภาพพืชในกลุ่มขาดธาตุอาหารที่ยังไม่แสดงรอยโรค (Pre-symptomatic) ออกจากชุดข้อมูลภาพที่จะนำไปฝึกฝนโครงข่ายประสาทเทียม

🏛️ ที่มา

ในสรีรวิทยาพืช N, P, K เป็นธาตุที่เคลื่อนย้ายได้ดีมากในท่อโฟลเอ็ม (Mobile Nutrients) ช่วง 5–7 วันแรกที่เริ่มขาดปุ๋ย พืชจะสลายสารอาหารในเมล็ดและใบเลี้ยงมาใช้ ทำให้ใบยังคงเขียวสดเหมือนกลุ่มปกติ หากนำภาพใบเขียวในระยะนี้ไปติดป้ายกำกับว่าขาดสารอาหาร จะเกิด Label Noise ขั้นรุนแรง ทำให้ CNN สับสนและมีความแม่นยำตกเหลือเพียง 50–65% ผู้วิจัยจึงพัฒนาเกณฑ์ตัดสินเชิงปริมาณเพื่อจำแนกภาพที่มีรอยโรคแท้จริง

🎯 หน้าที่ในระบบ A.E.G.I.S.

รับภาพพุ่มใบ 304 ภาพ ส่งภาพที่แสดงรอยโรคชัดเจนจริง (182 ภาพ) ไปให้ Stream A (Vision CNN) เรียนรู้ และกักภาพใบเขียวระยะแฝง (122 ภาพ) ไว้ให้ Stream B (เซนเซอร์น้ำ) ทำหน้าที่เรียนรู้การเตือนภัยล่วงหน้า

⚙️ การทำงานและสูตรคำนวณ

Z = (x - μ_ctrl) / σ_ctrl
Score_N = max(0, 0.35·Z_L + 0.35·Z_a + 0.30·Z_b) + 3.0·Yellow_Ratio
Score_P = max(0, -0.40·Z_L + 0.35·Z_a - 0.25·Z_b) + 3.0·Purple_Ratio
Score_K = max(0, 0.45·|Z_Δa| + 0.35·|Z_Δb| + 0.20·|Z_a|)
Threshold: Score >= 1.35 ผ่านเข้า Vision Training | Score < 1.35 กักไว้เป็นระยะแฝง

2. Vision Member A1: MobileNetV2 (Two-Stage Fine-Tuning)

Deep LearningCNNTransfer Learning

📌 ความหมาย

โครงข่ายประสาทเทียมสำหรับการมองเห็นเชิงลึกขนาดเบา (Lightweight Deep CNN) ที่ใช้โครงสร้าง Depthwise Separable Convolution ร่วมกับ Inverted Residuals

🏛️ ที่มา

Sandler et al. (Google Research, 2018) บทความ "MobileNetV2: Inverted Residuals and Linear Bottlenecks" ในงาน CVPR 2018 ออกแบบมาเพื่อลดพารามิเตอร์และการคำนวณลงมากกว่า 85% เมื่อเทียบกับ ResNet-50

🎯 หน้าที่ในระบบ A.E.G.I.S.

สกัดคุณลักษณะเชิงลึกและรูปทรงสัณฐานของใบพืช ส่งออกความน่าจะเป็น 4 คลาส (P_A1)

⚙️ การทำงานและขั้นตอนการเทรน

ใช้เทคนิค Two-Stage Fine-Tuning: Stage 1 ตรึงก้านเบส เทรนเฉพาะ Head ด้วย Adam (lr=1e-3, 8 epochs) $\rightarrow$ Stage 2 ปลดล็อก 12 เลเยอร์บนสุด เทรนด้วย Adam (lr=3e-5, 6 epochs) พร้อม EarlyStopping (ความแม่นยำ 85.37%)

3. Vision Member A2: Multi-Scale SE-Attention CNN

Attention MechanismCustom CNNMulti-Scale

📌 ความหมาย

โครงข่ายประสาทเทียมที่พัฒนาขึ้นโดยเฉพาะ ผสานการรับรู้ภาพหลายระยะ (กิ่ง 3x3 และ 5x5) เข้ากับกลไก Squeeze-and-Excitation เพื่อเพิ่มความสนใจเชิงช่องสัญญาณ

🏛️ ที่มา

Hu et al. (2018) บทความ "Squeeze-and-Excitation Networks" (ผู้ชนะเลิศ ImageNet 2017) ออกแบบมาเพื่อแก้ปัญหารอยโรคขนาดเล็ก เช่น จุดม่วงของแอนโทไซยานิน (-P) หรือขอบใบไหม้บางๆ (-K) ที่ฟิลเตอร์ขนาดเดียวมองข้าม

🎯 หน้าที่ในระบบ A.E.G.I.S.

ตรวจจับรอยโรคระดับจุลภาค (Micro-Pathological Features) ส่งออกความน่าจะเป็น 4 คลาส (P_A2)

⚙️ การทำงานและขั้นตอนการเทรน

Squeeze: z_c = GAP(u_c)
Excitation: s = σ( W_2 · ReLU(W_1 · z) )
Scale: X̃_c = s_c · u_c

เทรนขึ้นมาใหม่ตั้งแต่ต้น (Scratch Training) ด้วย Adam (lr=5e-4, 8 epochs) ความแม่นยำพุ่งขึ้นจาก 50.00% เป็น 90.24% (+40.24%)

4. Vision Member A3: Foliar Expert 44 มิติ (Physiological ML Sub-Ensemble)

Machine LearningHandcrafted FeaturesPlant Physiology

📌 ความหมาย

โมเดล Machine Learning แบบ Sub-Ensemble ที่คำนวณตัวเลขสรีรวิทยาพืช 44 ค่า สกัดจากพิกเซลใบพืชโดยตรง

🏛️ ที่มา

พัฒนาขึ้นตามหลักดัชนีพืชพรรณทางการเกษตรแม่นยำ (Meyer & Neto, 2008) และการสะสมเม็ดสีของ Marschner (2012) เพื่อทำหน้าที่เป็น "Anchor Model" ที่มั่นคง ไม่หลุดกรอบตามแสงเงา

🎯 หน้าที่ในระบบ A.E.G.I.S.

วิเคราะห์ความผิดปกติของเม็ดสีพืชและเนื้อสัมผัสตามหลักสรีรวิทยา ส่งออกความน่าจะเป็น 4 คลาส (P_A3)

⚙️ การทำงานและสถาปัตยกรรมภายใน

สกัด 44 มิติ: ดัชนีพืชพรรณ (ExG, ExR, NDI, VARI), ปริภูมิสี CIELAB/HSV, ผลต่างขอบใบกับกลางใบ (Δa*, Δb*), ความแปรปรวน Laplacian Variance และสัดส่วนสีเหลือง/ม่วง ส่งเข้า Sub-Ensemble: ExtraTrees (45%) + RandomForest (35%) + MLP (20%) ให้ความแม่นยำ 87.80%

5. Stream B: Sensor Ensemble (GBDT + Random Forest + Extra Trees)

Sensor AnalyticsEnsembleGBDT

📌 ความหมาย

ระบบปัญญาประดิษฐ์วิเคราะห์คุณสมบัติสารละลายธาตุอาหารในน้ำ (EC, pH, อุณหภูมิ, อัตราส่วนเทียบเบสไลน์, การดริฟต์) ผสานพลังของอัลกอริทึมต้นไม้ตัดสินใจ 3 รูปแบบ

🏛️ ที่มา

ผสาน Gradient Boosting (Friedman, 2001), Random Forest (Breiman, 2001) และ Extra Trees (Geurts et al., 2006) เพื่อให้ตรวจจับการพร่องของสารอาหารในน้ำได้ตั้งแต่วันแรกของการปลูก

🎯 หน้าที่ในระบบ A.E.G.I.S.

ทำนายสภาวะธาตุอาหารจากข้อมูลในน้ำ ส่งออกความน่าจะเป็น 4 คลาส (P_sen)

⚙️ สูตรการรวมผลลัพธ์

P_sen = 0.45·P_GBDT + 0.30·P_RandomForest + 0.25·P_ExtraTrees

ให้ความแม่นยำรวม 97.56% บน Holdout Set และ 100.00% บนชุดข้อมูลถังจริงในแปลงปลูก

6. กลไกตัดสินใจผสานสองสายขั้นสูง (Hierarchical Late-Fusion Engine)

Multimodal FusionDecision-LevelMeta-Decision

📌 ความหมาย

สถาปัตยกรรมการผสานข้อมูลหลากรูปแบบระดับการตัดสินใจ (Decision-Level Multimodal Fusion) ทำหน้าที่เป็นศาลชี้ขาดสูงสุดในการรวมเวกเตอร์ความน่าจะเป็นจากสายภาพ (P_vis) และสายเซนเซอร์ (P_sen)

🏛️ ที่มา

ทฤษฎี Multimodal Fusion พิสูจน์ว่า Late Fusion มีความทนทานต่อความล้มเหลว (Fault-Tolerant) สูงกว่า Early Fusion หากกล้องมีฝ้าเกาะ เซนเซอร์น้ำก็ยังทำงานต่อได้อย่างแม่นยำ

⚙️ สมการการตัดสินใจชี้ขาด

P_fused = 0.35 · P_vis + 0.65 · P_sen

ให้ความแม่นยำ 100.00% (Macro F1 = 1.0000) จำแนกถูกต้องครบทั้ง 12 จาก 12 หน่วยการทดลองจริงในแปลงปลูก

7. ปัญญาประดิษฐ์อธิบายเหตุผลได้ (Explainable AI: Grad-CAM)

Explainable AIHeatmapXAI

📌 ความหมาย

Gradient-weighted Class Activation Mapping ทำหน้าที่สร้างแผนภาพความร้อน (Heatmap) ซ้อนทับลงบนภาพถ่ายจริง เพื่อแสดงจุดที่โมเดลใช้ในการตัดสินใจ

🏛️ ที่มา

Selvaraju et al. (ICCV 2017) บทความ "Grad-CAM: Visual Explanations from Deep Networks" เพื่อเปิดเผยกล่องดำ (Black Box) ของ Deep Learning

⚙️ การทำงาน

คำนวณอนุพันธ์ย่อยของคะแนนคลาสเทียบกับ Feature Map ชั้น Conv สุดท้าย นำมาถ่วงน้ำหนักรวมผ่านฟังก์ชัน ReLU ได้แผนภาพความร้อนสีแดงส้มชี้ชัดไปยังรอยโรคบนใบจริง 100%

3. แนวทางตอบคำถามกรรมการสอบวิทยานิพนธ์ (Defense Q&A)

Q1: ทำไมต้องทำ Symptom-Gated Filtering ไม่ให้ CNN เรียนรู้ภาพทั้งหมดไปเลย?
คำตอบ: เพราะในสรีรวิทยาพืช วันที่ 1–7 ของการขาดธาตุ ใบพืชยังเขียวสดสมบูรณ์ (Pre-symptomatic phase) หากเราบังคับให้ CNN เรียนรู้ว่าใบเขียวนี้คือขาดธาตุ จะเกิด Label Noise ขั้นรุนแรง ทำให้ CNN สับสนว่าตกลงใบเขียวคือปกติหรือขาดสารอาหาร ความแม่นยำจึงตกเหลือเพียง 50–65% การทำ Symptom-Gating คัดแยกภาพใบเขียวในถังขาดธาตุออกไปให้เซนเซอร์ตรวจแทน ทำให้ความแม่นยำของโมเดลภาพพุ่งขึ้นถึง +22.39%
Q2: ทำไม Stream A ถึงมีทั้ง Deep Learning และ Handcrafted Features (Member A3)?
คำตอบ: Deep Learning มักจะมีพฤติกรรมเป็น "Black Box" ที่อาจไวต่อแสงเงาหรือสิ่งแปลกปลอมในฉากหลัง การใส่ Member A3 ที่คำนวณเวกเตอร์ฟิสิกส์ 44 ค่า (CIELAB, Margin-to-Core Gradient) เข้ามาด้วย จะทำหน้าที่เป็น "Anchor Model" คอยค้ำประกันความถูกต้องทางสรีรวิทยา ทำให้ผลลัพธ์ของ Stream A มีเสถียรภาพและไม่หลุดกรอบวิชาการ
Q3: ทำไมน้ำหนัก Late-Fusion ถึงให้เซนเซอร์น้ำมากกว่าภาพถ่าย (เซนเซอร์ 0.65 vs ภาพ 0.35)?
คำตอบ: เพราะค่าทางเคมีในสารละลาย (EC, pH, อุณหภูมิ) มีความไวในการตอบสนอง (Sensitivity) สูงกว่าสายตา เมื่อพืชดูดซึมปุ๋ยไป ค่า EC จะลดลงทันทีตั้งแต่วันแรก ในขณะที่ใบพืชต้องใช้เวลาหลายวันกว่าจะเกิดรอยเหลืองหรือรอยไหม้ การให้น้ำหนักเซนเซอร์ 0.65 ช่วยให้ระบบสามารถแจ้งเตือนล่วงหน้าได้ในระดับ Pre-symptomatic ก่อนที่พืชจะชะงักการเจริญเติบโต
