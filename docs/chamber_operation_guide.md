# คู่มือการทำงานของระบบ Chamber ตรวจวัดและกลไกแช่เก็บรักษาหัววัด pH
## (A.E.G.I.S. Automated Measurement Chamber & pH Probe Preservation Guide)

---

### 1. ปัญหาทางเคมีกายภาพและหลักการทางวิทยาศาสตร์ (Scientific Rationale)

#### ⚠️ ปัญหาที่พบในการใช้งานจริง:
- **หัววัด pH แบบหลอดแก้ว (Glass Electrode)** ประกอบด้วยกระเปาะแก้วบางพิเศษที่มีชั้นไฮเดรชันเจล (Hydrated Gel Layer) และสารละลายอ้างอิงภายในความเข้มข้นสูง ($3\text{M KCl}$)
- **ทำไมห้ามแช่ในน้ำเปล่าบริสุทธิ์ (DI Water / RO Water):**
  - น้ำ RO หรือน้ำเปล่าที่ปราศจากแร่ธาตุ มีความเข้มข้นของไอออนต่ำมาก (Osmotic Pressure ต่ำ)
  - เมื่อหัววัดแช่ในน้ำเปล่า จะเกิดแรงดึงออสโมซิสชะล้างไอออน $K^+$ และ $Cl^-$ ออกจากจุดเชื่อมต่อของเหลว (Porous Liquid Junction Leaching)
  - ทำให้สารละลายอ้างอิงเจือจาง ชั้นเจลแก้วบวมและสูญเสียประจุ ส่งผลให้ค่า pH เกิด **Calibration Drift อย่างรุนแรง**, การตอบสนองช้าลง (Slow Response), และหัววัดเสื่อมสภาพอย่างถาวรในเวลาอันสั้น
- **ทำไมห้ามปล่อยแห้ง (Dry Storage):**
  - หากปล่อยให้กระเปาะแก้วแห้ง ชั้นเจลไฮเดรตจะสูญเสียน้ำและแตกร้าว ทำให้ไม่สามารถสร้างความต่างศักย์ไฟฟ้าที่ถูกต้องได้

#### 💡 วิธีการแก้ไขด้วยระบบ Chamber ใหม่ (Wet-Standby Probe Preservation Protocol):
1. **แช่เก็บรักษาในน้ำตัวอย่าง (Nutrient Sample Solution Soak):** 
   - สารละลายธาตุอาหารจากถังปลูกมีไอออนของแร่ธาตุ (เช่น $K^+, NO_3^-, H_2PO_4^-$) ที่มีความดันออสโมซิสใกล้เคียงกับสารละลายอ้างอิง จึงช่วยรักษาชั้นเจลแก้วให้ชุ่มชื้นและคงสภาพประจุไอออนิกไว้ได้เป็นอย่างดี
2. **กฎเหล็กการล็อกค่า (No-Reading during Preservation Soak):**
   - ในช่วง Standby (พักรอบ 4 ชั่วโมง) น้ำที่แช่ใน Chamber จะอยู่นิ่ง ไม่มีการไหลเวียน ทำให้ค่า EC/pH ใน Chamber ไม่สะท้อนสภาวะจริงของถังปลูก
   - ระบบเฟิร์มแวร์จึง **สั่งล็อกไม่ให้อ่านค่าหรือส่งข้อมูล Telemetry ใดๆ ในช่วงพักแช่เก็บรักษานี้**
3. **ระบบหมุนเวียนแบบไร้การสูญเสีย (Zero Nutrient Waste):**
   - เมื่อเริ่มรอบใหม่ ระบบจะดูดน้ำแช่เดิมส่งกลับถังปลูกก่อน 4 วินาที จึงไม่มีการสูญเสียปุ๋ยหรือน้ำเลยแม้แต่หยดเดียว

### 2. ลำดับขั้นตอนการทำงานของ FSM (7-Phase Fluidic Sequence)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   PHASE_IDLE (โหมดพัก Standby 4 ชั่วโมง)                │
│    • ปลายโพรบ pH แช่อยู่ในน้ำตัวอย่างอย่างปลอดภัย (รักษาชั้นเจลแก้ว)       │
│    • ล็อกระบบ: ไม่มีการวัดค่าเซนเซอร์ และไม่มีการส่งข้อมูล Telemetry ใดๆ      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ เริ่มรอบใหม่ (Timer / คำสั่ง START)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ Phase 0 : PRE-RETURN (ปั๊มน้ำแช่เดิมกลับถังปลูก - 4.0 วินาที)          │
│    • ปั๊มไดอะแฟรม 2 [GPIO 6] ดูดน้ำแช่คืนถังปลูก 23.3L (Zero Loss)     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ Phase 1 : SAMPLING IN (ดูดน้ำตัวอย่างสดใหม่เข้า Chamber - 6.0 วินาที)   │
│    • ปั๊มไดอะแฟรม 1 [GPIO 5] ดูดน้ำสดจากถังปลูกจนท่วมหัววัดทั้งหมด      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ Phase 2 : SENSING & AI (พักน้ำนิ่ง 3.0s ➔ ตรวจวัดค่าส่งเข้า AI)        │
│    • พักน้ำนิ่ง 3 วินาที กรองฟองอากาศและลดสัญญาณกวน                     │
│    • วัดค่า: EC (ATC 25°C), pH, อุณหภูมิน้ำ ➔ ส่ง Telemetry สู่ AI     │
│    • AI ประมวลผล Late-Fusion ➔ ส่งคำสั่งจ่ายปุ๋ยกลับมา                 │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ Phase 3 : SAMPLE RETURN (ดูดน้ำที่ทดสอบแล้วกลับถังปลูก - 7.0 วินาที)   │
│    • ปั๊มไดอะแฟรม 2 [GPIO 6] ดูดน้ำตัวอย่างที่วัดเสร็จคืนถัง 100%      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ Phase 4 : TWO-TIER DOSING (สั่งจ่ายแม่ปุ๋ย N-P-K ตามคำสั่ง AI)         │
│    • ปั๊มรีดสาย 1, 2, 3 [GPIO 9-11] ทำงานพร้อมกันตามเวลาที่คำนวณ       │
│    • แต่ละตัวหยุดเองเมื่อครบเวลาของตัวนั้น (สูงสุด 30 วินาที/ตัว)        │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ Phase 7 : PROBE PRESERVATION (ดูดน้ำตัวอย่างมาแช่หัววัด - 3.0 วินาที)  │
│    • ปั๊มไดอะแฟรม 1 [GPIO 5] เปิดเพียง 3s ดูดน้ำจากถังปลูกมาท่วมปลายวัด│
│    • เมื่อครบ 3s ➔ ปิดปั๊ม เข้าสู่ PHASE_IDLE พักรอรอบถัดไป             │
└────────────────────────────────────────────────────────────────────────┘
```

### 3. ตารางกำหนดเวลาและพินควบคุมฮาร์ดแวร์ (Pinout & Timing Spec)

| ขั้นตอน (Phase) | ชื่อขั้นตอน | อุปกรณ์ที่ทำงาน | พิน GPIO | เวลาทำงาน | ฟังก์ชันการทำงาน |
| :---: | :--- | :--- | :---: | :---: | :--- |
| **0** | **Pre-Return** | ปั๊มไดอะแฟรม 2 | **GPIO 6** | **4,000 ms** (4s) | ดูดน้ำแช่เก็บรักษาเดิมส่งกลับคืนถังปลูก (Zero Waste) |
| **1** | **Sampling In** | ปั๊มไดอะแฟรม 1 | **GPIO 5** | **6,000 ms** (6s) | ดูดน้ำตัวอย่างสดใหม่จากถังปลูกเข้ากระบอก Chamber |
| **2** | **Measuring & AI** | เซนเซอร์ทั้งหมด | **GPIO 1, 2, 4** | **3,000 ms** (3s) | พักน้ำนิ่ง ➔ อ่านค่า pH, EC, Temp ➔ ส่ง AI วิเคราะห์ |
| **3** | **Sample Return** | ปั๊มไดอะแฟรม 2 | **GPIO 6** | **7,000 ms** (7s) | ดูดน้ำตัวอย่างที่วัดเสร็จแล้วส่งคืนถังปลูก 100% |
| **4** | **Two-Tier Dosing**| ปั๊มรีดสาย 1, 2, 3| **GPIO 9, 10, 11**| **5,000–10,000 ms** | จ่ายแม่ปุ๋ย N, P, K ตามคำสั่ง AI (ปั๊มทั้งสามตัวทำงานพร้อมกัน) |
| ~~5~~ | ~~Probe Rinse~~ | ปั๊มไดอะแฟรม 3 | **GPIO 7** | 5,000 ms | **ไม่ใช้ในรอบอัตโนมัติ** — สั่งทดสอบได้ด้วยมือเท่านั้น (MANUAL_RELAY) |
| ~~6~~ | ~~Drain Waste~~ | โซลินอยด์วาล์ว 12V| **GPIO 8** | 6,000 ms | **ไม่ใช้ในรอบอัตโนมัติ** — สั่งทดสอบได้ด้วยมือเท่านั้น |
| **7** | **Preservation** | ปั๊มไดอะแฟรม 1 | **GPIO 5** | **3,000 ms** (3s) | ดูดน้ำตัวอย่างปริมาณเล็กน้อยมาแช่ท่วมปลายกระเปาะแก้ว pH |
| **-** | **Standby** | ทุกรีเลย์ปิด (OFF)| - | **4 ชั่วโมง** | พักรอบโดยหัววัดแช่อยู่ในน้ำตัวอย่าง (**ไม่วัดค่า**) |

### 4. คำสั่งควบคุมและทดสอบผ่าน Serial Monitor (115200 Baud)

เมื่อเชื่อมต่อบอร์ด ESP32-S3 เข้ากับคอมพิวเตอร์ผ่านสาย USB สามารถเปิด Serial Monitor เพื่อพิมพ์คำสั่งควบคุมได้ดังนี้:

- `START` หรือ `RUN` — สั่งเริ่มต้นการทำงานเต็มลูป 7 ขั้นตอน (รวม Pre-Return 4s และ Preservation Soak 3s)
- `READ` — สั่งอ่านค่าเซนเซอร์แบบ Manual (จะแสดงค่าปัจจุบันใน Chamber)
- `STOP` — ตัดการทำงานของปั๊มและวาล์วทุกตัวทันที (Emergency Abort)
- `TEST <หมายเลขรีเลย์ 1-7> <เวลา ms>` — ทดสอบสั่งเปิดรีเลย์แต่ละตัวตามเวลาที่ต้องการ เช่น:
  - `TEST 1 3000` ➔ ทดสอบเปิดปั๊มดูดน้ำเข้า (Diaphragm 1) นาน 3 วินาที
  - `TEST 2 4000` ➔ ทดสอบเปิดปั๊มดูดน้ำกลับ (Diaphragm 2) นาน 4 วินาที
  - `TEST 3 5000` ➔ ทดสอบเปิดปั๊มน้ำล้าง RO (Diaphragm 3) นาน 5 วินาที
  - `TEST 4 6000` ➔ ทดสอบเปิดโซลินอยด์วาล์วเดรน นาน 6 วินาที

### 5. ข้อควรระวังและการดูแลรักษาฮาร์ดแวร์จริง

1. **ระดับน้ำแช่เก็บรักษาใน Chamber (Phase 7):**
   - ระยะเวลา 3 วินาทีถูกคำนวณมาเพื่อให้ระดับน้ำใน Chamber สูงพ้นปลายกระเปาะแก้ว pH เล็กน้อย (~20–30 ml)
   - หากความยาวท่อยางเปลี่ยนไป สามารถปรับจูนค่า `TIME_PRESERVATION_SOAK_MS` ในไฟล์ `config.h` ได้ตามความเหมาะสม
2. **การล้างทำความสะอาดตามรอบบำรุงรักษา:**
   - แม้ระบบจะมีกลไกแช่เก็บรักษาอัตโนมัติ แต่แนะนำให้ตรวจสอบขวดน้ำล้าง RO และถังน้ำทิ้งสัปดาห์ละ 1 ครั้ง
   - ควรถอดหัววัด pH มา Calibrate ด้วยน้ำยาบัฟเฟอร์ pH 4.01 และ 6.86 ทุกๆ 30 วัน เพื่อความเที่ยงตรงสูงสุด
